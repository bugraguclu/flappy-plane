# Flappy Plane

Tarayıcıda oynanan, tek dosyalık uçuş oyunu. Kıl payı primleri, madalyalar, mağaza ve
kostümler; tüm ilerleme cihazın kendi belleğinde (localStorage) saklanır.

**Oyna:** https://pureko-tr.github.io/flappy-plane/

Telefonda tam ekran oynamak için linki aç ve *Ana Ekrana Ekle* (iPhone: Paylaş menüsü,
Android: Chrome menüsü) de. Bir kez açtıktan sonra internetsiz de çalışır.

`index.html` kendi kendine yeter — indirip çift tıklayarak da oynayabilirsin.
